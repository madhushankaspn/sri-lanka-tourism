## ✨ Features

- **Hero Slideshow** — Full-width image carousel showcasing iconic Sri Lankan destinations
- **Popular Destinations Grid** — Quick-access cards for top places like Sigiriya Rock Fortress and the Ancient City of Polonnaruwa
- **Individual Place Pages** — Dedicated pages for each destination with details, photos, and highlights
- **Photos & Videos** — A media gallery of Sri Lanka's best moments
- **User Authentication** — Login page with user session display in the navbar
- **Admin Panel** — Backend management page for site content
- **Fully Responsive** — Optimized for desktop, tablet, and mobile screens
- **Contact Page** — For visitor inquiries

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/your-username/discover-sri-lanka.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd discover-sri-lanka
   ```

3. **Open in browser**
   ```bash
   open index.html
   ```
   Or simply double-click `index.html` in your file explorer.

> No build tools or dependencies required — it's pure HTML, CSS, and JS!
